# 槓桿做多這種交易模式 — Requirements Brief

## Goal

交易模式現在只有兩種：**現貨**與**多空反手**。

它們各自答了兩個問題，而那兩個問題**其實是分開的**：

| | 做得了空嗎 | 借得到錢嗎 |
| :--- | :--- | :--- |
| **現貨** | 做不了 | 借不到 |
| **多空反手** | 做得了 | 借得到 |

兩個問題各有兩種答案，卻只給了兩種模式。少的那一種是：
**做不了空，但借得到錢。**

那不是一個假想的組合。它就是**永續合約只做多**——使用者在合約帳戶上開一個
多倉、上一點槓桿，而且從頭到尾不打算放空。想做這件事的人不少，
真正在做這件事的人也不少。

**而系統現在對這件事的態度是自相矛盾的。**

一台機器人可以照一份**現貨**交易策略，建議一個 **1.8 倍**的部位——
存得起來、跑得起來、訊息照送。可是拿同樣這份交易策略、同樣 1.8 倍去**重演**，
整份會被拒絕，理由是「現貨開不了槓桿」。

於是使用者手上有一台**正在運作、卻驗證不了**的機器人。
**兩扇門對同一件事講兩種話**，而他只能在其中一扇門後面看到成績單。

問題不在哪一扇門判錯了。**兩扇門講的都對，錯的是他手上只有兩種模式可挑。**
「現貨」對他的帳戶來說是錯的詞——他不是拿現金換東西，他是在合約帳戶上做多。
他挑現貨，只因為另一個選項會讓他被反手做空，而那是他更不想要的。

這個切片補上第三種交易模式：**槓桿做多**。
倉位的行為與現貨一字不差——只做多、賣出就平倉回現金、空手時聽到賣出什麼都不發生——
**但它借得到錢**。於是重演與機器人終於對同一份規則講同一種話，
而使用者那台機器人在做的事，他終於也驗證得了。

## Requirements

### 交易模式從兩種變三種

交易模式從此**三選一**：**多空反手**、**現貨**、**槓桿做多**。

- **槓桿做多的倉位行為，與現貨一字不差。** 聽到買入，空手就開多倉、已是多倉當作沒聽到；
  聽到賣出，有多倉就平掉、錢回到可用資金、之後空手；**空手時聽到賣出什麼都不發生**；
  聽到持平不動作。**永遠不會出現空倉**，交易明細每一筆的方向都是做多。
  同一棒不會既平又開。
- **槓桿做多與現貨唯一的差別，是它借得到錢。**

**用「槓桿做多」這個詞，不叫「永續合約」。**
它描述的是**這套規則能做什麼**（只做多、能借錢），不是**在哪裡做**。
一樣的規則放到別的地方、別的商品上照樣成立，
而把場所寫進名字裡，換個地方就得再發明一個詞。

### 三種模式各自能做什麼

| 交易模式 | 賣出是什麼意思 | 借得到錢嗎 |
| :--- | :--- | :--- |
| 多空反手 | 平掉多倉，同一棒反手開空 | 借得到 |
| 現貨 | 平倉回現金，空手時什麼都不發生 | **借不到** |
| 槓桿做多 | 平倉回現金，空手時什麼都不發生 | **借得到** |

- **「做不做得了空」與「借不借得到錢」是兩個獨立的問題。**
  三種模式是這兩個問題的三種合法組合。第四種（做得了空、卻借不到錢）
  不存在——**放空本來就要先借到東西才賣得出去**，所以它不是被漏掉，是它不成立。

### 沒填會怎樣、填錯會怎樣——一個字都不改

- **沒填**仍然是**多空反手**。
- **填一個認不得的值，整份拒絕**，並說出現在有哪**三**種可選——
  唯一的變化是那句話裡多了一個選項。
- **既有的每一份交易策略照舊**：填現貨的還是現貨，填多空反手的還是多空反手，
  沒填的還是多空反手。**沒有任何一份會被自動改成槓桿做多**——
  改掉一份交易策略的交易模式，等於改掉它每一張成績單的意義，
  那是使用者自己要做的決定。

### 重演：槓桿做多借得到錢

- 交易模式是**槓桿做多**、槓桿倍數大於一 → **接受**，照既有的槓桿規矩重演：
  曝險是押注金額的幾倍、賺賠與成本都照曝險算、**價格逆著走到撐不住就強制平倉**。
- 強制平倉的規矩**一條都不新增**：強平距離怎麼算、維持保證金率留白是多少、
  止損與強平誰先到、被強平時收回多少、成績單上那一格怎麼填，
  **全部沿用既有的那一套**。槓桿做多只是多一種**允許**它發生的模式。
- **槓桿做多只會有多倉**，所以強平價永遠在進場價**下方**。
- 交易模式是**現貨**、槓桿倍數大於一 → **仍然整份拒絕**，一個字都不改。
- 三種模式在槓桿倍數留白時，結果與這一刀之前**逐字相同**。

### 機器人：建議的槓桿不能超出那份規則允許的範圍

**一台機器人所建議的槓桿，必須是它所引用的那份交易策略做得到的事。**

- 機器人引用一份**現貨**交易策略，部位規劃又填了大於一的槓桿倍數
  → **整台拒絕存**，理由與重演那一邊**一字不差**：現貨借不到錢。
- 機器人引用**槓桿做多**或**多空反手**的交易策略，填大於一的槓桿倍數
  → 照舊存得起來。
- 槓桿倍數**留白或填一**時，三種模式都存得起來——沒有借錢，就沒有這條規則。

**這是新增的一道關卡。** 在此之前，機器人存自己的部位規劃時
**從來沒有讀過它所引用的那份交易策略**，所以這件事擋不了。
補上之後，同一組設定在**兩扇門後面得到同一個答案**。

**既有的機器人不會被回頭作廢。**
已經存在、已經在跑的機器人照樣跑，不會因為這道新關卡而被停掉或刪掉。
關卡只在**下一次存它的時候**生效——那時使用者會看到那句話，
並且知道他該做的是把那份交易策略改成槓桿做多。

### 機器人的訊息：照現貨的寫法，但講出交易模式

- **動詞照現貨寫**：`買入` 與 `出場`，不是 `做多`／`做空`。
  槓桿做多的人**做不了空**，「賣出」對他一樣是一句他不一定做得到的話——
  賣出照信號本身就會送出，而他空手的時候也收得到。
- **多一行講出交易模式**，與多空反手一樣。
  現貨不印那一行，是因為「買入／出場」本身已經說完了他要做的事；
  槓桿做多**不一樣**——同樣一句「買入」，在現貨是拿現金去換，
  在槓桿做多是**借錢開一個會被強制平倉的倉位**。那是他必須知道的差別。
- **槓桿與名目部位那兩行照既有規矩印**：填了大於一的槓桿就印，沒填就不印。
- **各來源怎麼說那一段不動**，照樣寫買入／賣出／持有——
  那幾行是策略腳本自己吐出來的信號，而信號永遠只有三種。

### 使用者挑得到這個新選項

- 畫面上建立與修改交易策略的地方，交易模式**從兩個選項變三個**。
- 助手在替使用者寫或改交易策略時，**認得這三種**，
  並且說得出它們差在哪——使用者說「我在幣安開合約，只做多，上一點槓桿」時，
  它要挑得到槓桿做多，而不是退而求其次挑現貨。
- 重演一支**策略腳本**時（那條路上沒有交易策略可問，使用者自己指定交易模式）
  同樣認得這三種，規則一字不差。

## Out of Scope

- **只做空、能借錢的模式。** 「只放空不做多」是槓桿做多的鏡像，
  但沒有人開口要，不為了對稱生一個沒人用的選項。
- **把交易模式拆成兩個各自獨立的設定。** 「做不做得了空」與「借不借得到錢」
  確實是兩個問題，但四種組合裡只有三種成立——放空本來就要借。
  拆成兩格會讓使用者填得出一個不存在的東西，然後系統再回頭拒絕他。
  **三個選項比兩格加一條規則誠實。**
- **自動把既有的現貨交易策略改成槓桿做多。** 就算它底下那台機器人明顯是在跑合約，
  改掉一份交易策略的交易模式等於改掉它每一張成績單的意義。系統說出哪裡不一致，
  改不改由使用者決定。
- **回頭作廢既有的機器人。** 新關卡只在下一次存的時候生效。
  把正在跑的機器人停掉，是拿走他正在用的東西來換一致性。
- **資金費率。** 永續合約每隔幾小時要付（或收）的那筆錢。
  它是慢性失血、不會讓人看到一個假的數字，與這一刀無關。
- **強制平倉本身的任何規矩。** 強平距離、維持保證金率、止損與強平的先後、
  賠不超過押注金額、成績單那一格——**全部沿用，一條都不改**。
  這一刀只是多一種模式**允許**它發生。
- **機器人真的去下單。** 機器人從頭到尾只送建議，這件事不變。

## Context / Background

- **為什麼是加第三種模式，不是放寬現貨。**
  「現貨開不了槓桿」不是一條過嚴的規則，它是**對的**：
  現貨就是拿現金換東西，沒有人借錢給你。放寬它等於讓「現貨」這個詞
  開始指兩件不同的事，而那正是現在這個矛盾的源頭。

- **為什麼機器人那一邊擋不了，不是因為忘了寫。**
  機器人存的是「我要用哪一份交易策略」這個指名，
  它在檢查自己的部位規劃時**手上根本沒有那份交易策略**。
  所以這不是補一個 if，是讓機器人在存自己的時候**讀得到它所引用的那份規則**。
  這是這一刀唯一的結構性改動。

- **為什麼機器人訊息要多印交易模式那一行。**
  現貨不印，是因為「買入」對他就是拿現金去換，沒有第二種讀法。
  槓桿做多的「買入」是**借錢開一個會被強制平倉的倉位**——
  同樣三個字，風險差一個量級。不講出來，他會照現貨的心情去執行。

- **使用者現在就有一台這樣的機器人。**
  它引用一份現貨交易策略、建議 1.8 倍，而且正在跑。
  它會是這一刀之後第一個被指出不一致的東西——這正是這一刀存在的理由，
  不是它的副作用。
