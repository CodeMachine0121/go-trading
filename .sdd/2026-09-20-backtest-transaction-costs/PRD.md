## 1. Background & Goal (Why & Goal)

### Problem Statement

重演從頭到尾只算一件事：**價格動了多少**。

買一次要付手續費，賣一次要付手續費再加一筆稅，而這些錢在重演裡**從來沒有離開過帳戶**。
成績單上的「可用資金」與「最後剩多少」，描述的是一個**不用付錢就能交易**的世界。

台股一趟完整進出（十萬元、手續費六折）要付 471 元，**原地打平就虧 0.47%**。
加密貨幣兩邊各 0.1%，一趟 0.2%。

但真正的問題不是「少算了 0.47%」，而是**偏誤與交易次數成正比**：

| 一支不賺不賠的策略，本金一百萬 | 成績單會說 | 實際上會剩 | 差距 |
|---|---:|---:|---:|
| 一年進出 4 趟 | 100 萬 | 98.1 萬 | 1.9% |
| 一年進出 40 趟 | 100 萬 | 82.8 萬 | 17.2% |
| 一年進出 200 趟 | 100 萬 | **38.9 萬** | **61.1%** |

訊號越密集的策略被高估越多，而那種策略的成績單看起來最漂亮。
使用者把兩支策略並排比較的時候，他以為自己在比「誰抓價差抓得準」，
實際上他在比「誰的成本被藏得比較深」——**而排名可能是反的**。

同樣的落差也出現在勝率上。一支「賺 0.3% 就跑」的台股策略每一筆實際都是虧的，
但成績單目前會說它勝率七成。那不是一個比較不精確的數字，那是一句謊話。

### Expected Outcome

發動重演時可以多說兩件事：**進場成本率**與**出場成本率**（成交金額的百分點，各自選填）。

填了，重演就**真的把那筆錢從可用資金裡扣掉**——
最後剩多少、總報酬率、勝率、最大回撤、資金曲線、每一筆交易的損益
**全部反映那些付出去的錢**。成績單還會說出**總共付了多少**。

不填，就**一個數字都不變**。

於是使用者第一次能回答那兩個他一直該問的問題：

- 「我這支策略扣掉手續費之後，還賺錢嗎？」
- 「它是**抓價差不行**，還是**被手續費吃掉**？」

### Out of Scope

| 不做 | 為什麼 |
|:---|:---|
| 每筆最低手續費（台股 20 元那種） | 只在成交金額很小時才咬得到（六折下約兩萬三以下），低於本系統實際使用的規模。**這是明知故犯的低估**，要寫進成績單的說明 |
| 滑價 | 成交仍在那個價位本身，與出場價位那一刀的立場一字不差。要改是另一刀 |
| 固定金額的成本（每筆收多少錢，不看金額） | 台股與加密貨幣都是比例制，這一刀只做用得到的那一種 |
| 按風險量計價的成本 | 那是選擇權那類商品的收法，這裡只有成交金額一種名目 |
| 借券費、資金費率、隔夜利息、槓桿與保證金 | 仍然一概不計 |
| 機器人建議的部位要不要預留成本 | 機器人維持現狀。代價寫明：同樣設定下，它建議的部位與重演模擬的部位會差一點點 |
| 把那兩格存回策略腳本或交易策略 | 與這一次的參數值、初始資金同一類——**跟著這一次走** |
| 同一次重演比較「有成本 / 沒成本」 | 一次一種，要對照就跑兩次——與交易模式、出場價位一字不差的理由 |

## 2. User Personas

| Persona | 描述 | 他在這一刀裡要什麼 |
|:---|:---|:---|
| **策略調校者（James 本人）** | 唯一使用者。寫腳本、跑重演、讀成績單、調整，一圈一圈來 | 他手上每一張成績單都是在「交易免費」的前提下算出來的。他要知道扣掉手續費之後，哪一支還站得住 |
| **AI 助手（透過連接器）** | 代替他跑那一整圈 | 「建規則 → 重演 → 讀成績單 → 調整」。調整裡最有價值的一項就是「把費率填進去再跑一次」，所以它必須說得出那兩格 |

## 3. User Stories & Acceptance Criteria

### US-01 — 發動重演時說得出兩個成本率 [priority: P0]

> **作為** 策略調校者
> **我想要** 在發動重演時填上進場成本率與出場成本率
> **以便** 成績單算的是我真正要付錢去跑的那個策略，不是一個交易免費的幻想版本

**Acceptance Criteria**

- **AC-01.1** 兩個欄位皆為**選填的百分點**，說的是**這一筆成交金額的百分之幾**。
- **AC-01.2** 兩格都留白 → **一概不計**：成績單與這一刀之前**每一個數字逐字相同**。
- **AC-01.3** 只填進場成本率 → **出場也收同一個費率**（出場留白即沿用進場）。
- **AC-01.4** 只填出場成本率 → 進場不收、出場收。
- **AC-01.5** **三個入口都要能說**，行為一字不差：重演一支策略腳本、重演一份交易策略、助手發動的重演。
- **AC-01.6** 任一成本率**為負** → 整次拒絕，訊息說出是哪一格、以及「不得為負」。
- **AC-01.7** 任一成本率**超過 100** → 整次拒絕，訊息說出「不得超過 100%——成本不會超過成交金額本身」。
- **AC-01.8** 正好 100 → 送得出去（整筆成交金額都拿去付成本，荒謬但算得出來）。

```gherkin
Scenario: 兩個成本率都填
  Given 進場成本率填 1、出場成本率填 1
  When 發動重演
  Then 進場與出場兩邊都收費

Scenario: 兩格都留白就完全不收
  Given 進場成本率與出場成本率都留白
  When 發動重演
  Then 成績單的每一個數字與這一刀之前逐字相同

Scenario: 只填進場成本率，出場沿用
  Given 進場成本率填 1、出場成本率留白
  When 發動重演
  Then 出場也依成交金額收 1%

Scenario: 只填出場成本率
  Given 進場成本率留白、出場成本率填 1
  When 發動重演
  Then 進場不收費，出場依成交金額收 1%

Scenario: 成本率為負整次拒絕
  Given 進場成本率填 -1
  When 發動重演
  Then 整次重演被拒絕，訊息說出進場成本率不得為負
  And 不回傳任何部分結果

Scenario: 成本率超過一百整次拒絕
  Given 出場成本率填 101
  When 發動重演
  Then 整次重演被拒絕，訊息說出不得超過 100%

Scenario: 成本率正好一百送得出去
  Given 進場成本率填 100
  When 發動重演
  Then 重演照常執行

Scenario: 重演一份交易策略與重演一支策略腳本一字不差
  Given 同一段行情、同樣的兩個成本率
  When 分別重演一支策略腳本與一份只含該腳本的交易策略
  Then 兩張成績單的每一個數字相同
```

### US-02 — 成本真的從可用資金裡扣掉 [priority: P0]

> **作為** 策略調校者
> **我想要** 付掉的手續費真的讓我的錢變少
> **以便** 下一次開倉押的是我**真正還剩下的錢**，而不是一個從沒付過錢的帳戶

**Acceptance Criteria**

- **AC-02.1** 進場成本在**開倉當下**從可用資金扣掉。
- **AC-02.2** 出場成本在**平倉當下**從收回的現金裡扣掉。
- **AC-02.3** **全押**：可用資金全部變成「這一筆交易」——部位**加上**它的進場成本；
  部位比可用資金**略小**，開完倉可用資金為零。
- **AC-02.4** **押幾成、押固定金額**：押的金額仍然是那個數，進場成本**另外**從可用資金扣。
- **AC-02.5** **付不起就跳過這次開倉**：要付得起「押的金額 **加上** 進場成本」才開得成。
  付不起時這次開倉不發生，重演**繼續走**、不算失敗、不計入開倉次數——與既有規則一字不差。

```gherkin
Scenario: 全押時可用資金分成部位與它的進場成本
  Given 可用資金 10100、進場成本率 1
  When 這一棒說買入、成交價 100
  Then 部位是 10000、進場成本是 100、可用資金變成 0
  And 這一注買到 100 個單位

Scenario: 押幾成時成本另外扣
  Given 可用資金 10100、押五成、進場成本率 1
  When 這一棒說買入
  Then 部位是 5050、進場成本是 50.5、可用資金剩 4999.5

Scenario: 全押且成本率是一百
  Given 可用資金 10100、進場成本率 100
  When 這一棒說買入
  Then 部位是 5050、進場成本是 5050、可用資金變成 0

Scenario: 付不起押的金額加上進場成本就跳過
  Given 可用資金正好 10000、押固定金額 10000、進場成本率 1
  When 這一棒說買入
  Then 這次開倉不發生
  And 重演繼續走到下一棒
  And 開倉次數沒有增加

Scenario: 同樣的情況在不填成本時開得成
  Given 可用資金正好 10000、押固定金額 10000、兩個成本率都留白
  When 這一棒說買入
  Then 開倉成功
```

### US-03 — 成本按成交金額收，做空也一樣 [priority: P0]

> **作為** 策略調校者
> **我想要** 出場成本算的是那一刻實際成交的金額
> **以便** 做空那幾筆的成本不會被算錯，而我根本看不出來

**Acceptance Criteria**

- **AC-03.1** 進場成本 ＝ 押下去的金額 × 進場成本率。
- **AC-03.2** 出場成本 ＝ **平倉時實際成交的金額** × 出場成本率。
  成交金額是「這一注的單位數 × 出場價」，**不是**這一注帳面上值多少。
- **AC-03.3** 做多時兩者剛好相等，**做空時不相等**——這一條只有做空看得出差別。
- **AC-03.4** 成本**永遠是支出**：不會因為方向是空、或因為那一趟是虧的，變成一筆收入。

```gherkin
Scenario: 做空的出場成本看成交金額而不是帳面價值
  Given 多空反手、可用資金 10100、兩個成本率都是 1
  And 第一棒收 100 說賣出，放空 100 個單位、進場成本 100
  When 第三棒收 90 說買入
  Then 出場成交金額是 9000、出場成本是 90
  And 這一筆的損益是 810
  And 最後剩 10910

Scenario: 做空虧錢時成本仍然是支出
  Given 多空反手、可用資金 10100、兩個成本率都是 1
  And 第一棒收 100 說賣出，放空 100 個單位、進場成本 100
  When 第三棒收 110 說買入
  Then 出場成交金額是 11000、出場成本是 110
  And 這一筆的損益是 -1210
  And 最後剩 8890

Scenario: 做多的一趟
  Given 可用資金 10100、全押、兩個成本率都是 1
  And 第一棒收 100 說買入，部位 10000、進場成本 100、買到 100 個單位
  When 第三棒收 110 說賣出
  Then 出場成交金額是 11000、出場成本是 110
  And 這一筆的損益是 790
  And 最後剩 10890
```

### US-04 — 逐筆損益與勝率都是扣掉成本之後的淨額 [priority: P0]

> **作為** 策略調校者
> **我想要** 一筆交易的損益就是我口袋真正的變化
> **以便** 勝率不再把「賺不過手續費」的那幾筆算成贏

**Acceptance Criteria**

- **AC-04.1** 一筆交易的損益 ＝ 價差 **減** 這一筆的進場成本 **減** 這一筆的出場成本。
- **AC-04.2** 一趟**原地打平**（進場價等於出場價）的交易，損益正好是**負的那兩筆成本**。
- **AC-04.3** 價差是賺的、但賺不過兩筆成本的那一趟，**不算贏**。
- **AC-04.4** 勝率因此是「扣掉成本還賺的比例」。
- **AC-04.5** **每一筆交易多記兩個數字**：這一筆的進場成本、這一筆的出場成本。
- **AC-04.6** 兩格留白時，每一筆的兩個成本數字都是 **0**，損益與勝率與這一刀之前逐字相同。

```gherkin
Scenario: 原地打平的一趟虧的正好是兩筆成本
  Given 可用資金 10100、全押、兩個成本率都是 1
  And 第一棒收 100 說買入，部位 10000、進場成本 100
  When 第三棒收 100 說賣出
  Then 出場成本是 100
  And 這一筆的損益是 -200
  And 這一筆不算贏
  And 最後剩 9900

Scenario: 賺不過成本的一趟不算贏
  Given 一趟交易的價差賺 150、兩筆成本合計 210
  When 讀那一筆交易
  Then 損益是 -60
  And 這一筆不算贏

Scenario: 勝率只算扣掉成本還賺的那幾筆
  Given 三趟交易的價差都是賺的，其中兩趟賺不過它們的成本
  When 讀成績單
  Then 勝率是三分之一

Scenario: 不填成本時每一筆的成本都是零
  Given 兩個成本率都留白
  When 讀交易明細
  Then 每一筆的進場成本與出場成本都是 0
  And 勝率與這一刀之前逐字相同
```

### US-05 — 成績單說得出總共付了多少 [priority: P0]

> **作為** 策略調校者
> **我想要** 一眼看到這次重演總共付了多少手續費
> **以便** 判斷這支策略是抓價差不行，還是被手續費吃掉

**Acceptance Criteria**

- **AC-05.1** 成績單多一個**累計成本**。
- **AC-05.2** 累計成本 ＝ 所有已平倉交易的進場成本與出場成本總和
  **加上** 結束時還開著那一注**已經付掉的**進場成本。
- **AC-05.3** 兩格留白時，累計成本是 **0**。

```gherkin
Scenario: 累計成本是一趟的兩筆成本相加
  Given 一次重演只做了一趟交易，進場成本 100、出場成本 110
  When 讀成績單
  Then 累計成本是 210

Scenario: 還開著的那一注只算它已經付掉的進場成本
  Given 一次重演開了一注、進場成本 100，走完時那一注還開著
  When 讀成績單
  Then 累計成本是 100

Scenario: 不填成本時累計成本是零
  Given 兩個成本率都留白
  When 讀成績單
  Then 累計成本是 0
```

### US-06 — 還開著的那一注不預扣出場成本 [priority: P0]

> **作為** 策略調校者
> **我想要** 資金曲線上每一點只反映我已經真的付掉的錢
> **以便** 那條線描述的是發生過的事，不是一件還沒發生的事

**Acceptance Criteria**

- **AC-06.1** 資金曲線上的每一點**不預扣**還沒付的出場成本。
- **AC-06.2** 進場成本在開倉那一棒**當場**反映在資金曲線上——那一點會立刻掉一筆進場成本。
- **AC-06.3** 最大回撤因此會比不計成本時**略大**。那不是誤差，那是真的付掉的錢。
- **AC-06.4** 結束時還開著的那一注：進場成本已扣、出場成本未扣，
  「最後剩多少」因此**樂觀一筆出場成本**——這件事要寫進成績單的說明。
- **AC-06.5** 還開著的那一注照舊**不進交易明細**（它沒有出場）。

```gherkin
Scenario: 開倉那一棒資金曲線立刻掉一筆進場成本
  Given 可用資金 10100、全押、進場成本率 1
  When 第一棒收 100 說買入
  Then 那一棒的資金曲線點是 10000

Scenario: 走完時還開著的那一注不預扣出場成本
  Given 第一棒開倉、部位 10000、進場成本 100，走完時那一注還開著
  And 最後一棒收 110
  When 讀成績單
  Then 最後剩 11000
  And 交易明細裡沒有這一注
```

### US-07 — 助手也說得出成本，以及那兩個出場距離 [priority: P0]

> **作為** AI 助手
> **我想要** 發動重演時說得出兩個成本率與兩個出場距離
> **以便** 我跑出來的成績單與使用者自己跑的，在同樣設定下是同一張

**Acceptance Criteria**

- **AC-07.1** 助手發動重演時說得出**進場成本率與出場成本率**。
- **AC-07.2** 助手發動重演時說得出**止損距離與止盈距離**（本刀補齊，先前漏了）。
- **AC-07.3** 助手填什麼、使用者自己填同樣的值，**成績單逐字相同**。
- **AC-07.4** 助手什麼都不填 → 不計成本、不模擬出場價位，與這一刀之前一字不差。
- **AC-07.5** 拒絕的措辭與使用者自己發動時**一字不差**。

```gherkin
Scenario: 助手填的與使用者填的跑出同一張成績單
  Given 同一段行情與同一份交易策略
  When 助手發動重演並填進場成本率 1、止損距離 2
  And 使用者自己發動重演並填同樣的兩個值
  Then 兩張成績單的每一個數字相同

Scenario: 助手什麼都不填
  Given 助手發動重演，成本率與出場距離都不填
  When 走完
  Then 成績單與這一刀之前一字不差

Scenario: 助手填了不合法的成本率
  Given 助手發動重演並填進場成本率 -1
  When 發動重演
  Then 整次重演被拒絕
  And 拒絕的措辭與使用者自己發動時一字不差
```

### US-08 — 畫面上填得出那兩格、讀得出那筆錢 [priority: P0]

> **作為** 策略調校者
> **我想要** 在重演的畫面上填那兩個費率、在成績單上看到累計成本
> **以便** 我不用為了算一次含成本的重演而去打指令

**Acceptance Criteria**

- **AC-08.1** 兩種重演的畫面都填得出那兩格，兩格併排成一組。
- **AC-08.2** 出場那一格要說得出「留白就跟進場一樣」。
- **AC-08.3** 成績單上看得到**累計成本**。
- **AC-08.4** 交易明細的每一筆看得到它自己的進場成本與出場成本。
- **AC-08.5** 兩格留白時畫面一切如常——沒有成本欄位以外的任何變化。

## 4. Business Flow & Logic

### 一棒怎麼走（粗體是這一刀新增的）

```
每一根已走完的 K 線，依序：
  1. 先看出場價位（既有）
       碰到了 → 以該價位平倉
                  → **算出場成本 = 單位數 × 出場價 × 出場成本率**
                  → **收回現金 = 那一注在該價位值多少 − 出場成本**
                  → **這一筆的損益 = 價差 − 進場成本 − 出場成本**
  2. 再套這一棒的信號（既有）
       要平倉 → 同上那一整套
       要開倉 → **可押上限 = 可用資金 ÷ (1 + 進場成本率)**
                 押多少照既有三種模式算
                 **押的金額 > 可押上限 → 跳過這次開倉**
                 **進場成本 = 押的金額 × 進場成本率**
                 **可用資金 −= 押的金額 + 進場成本**
  3. 記下這一棒的資金曲線點（既有，數字自然變了）
```

### 為什麼「可押上限」這樣定

三種押法要用**同一個**判斷，否則每一種都會長出自己的邊界：

| 押法 | 押多少 | 付得起嗎 |
|:---|:---|:---|
| 全押 | **可押上限**本身 | 恆成立 |
| 押幾成 | 可用資金 × 那幾成（**意思不變**） | 押的金額 ≤ 可押上限 |
| 押固定金額 | 那個數（意思不變） | 押的金額 ≤ 可押上限 |

「押的金額 ≤ 可用資金 ÷ (1 + 進場成本率)」與
「押的金額 + 它的進場成本 ≤ 可用資金」是同一句話。
成本率為零時可押上限就是可用資金本身——**既有的每一條規則一個字都不用改**。

### Core Business Rules

| # | 規則 |
|:---|:---|
| R-1 | 兩個成本率**各自選填**，說的是**成交金額的百分點** |
| R-2 | **出場留白即沿用進場**；兩格都留白即完全不計 |
| R-3 | 成本率為負或超過 100 → **整次拒絕**；正好 100 允許 |
| R-4 | 進場成本 ＝ 押的金額 × 進場成本率，**開倉當下**從可用資金扣 |
| R-5 | 出場成本 ＝ **單位數 × 出場價** × 出場成本率，**平倉當下**從收回的現金扣 |
| R-6 | 成本**永遠是支出**，不因方向或盈虧變成收入 |
| R-7 | 開得成的條件是付得起「押的金額 ＋ 進場成本」；付不起就**跳過這次開倉** |
| R-8 | 一筆交易的損益 ＝ 價差 − 進場成本 − 出場成本（**淨額**） |
| R-9 | 勝率讀的是淨額，因此是「扣掉成本還賺的比例」 |
| R-10 | 還開著的那一注**不預扣**出場成本 |
| R-11 | 累計成本 ＝ 已平倉的所有成本 ＋ 還開著那一注已付的進場成本 |
| R-12 | 三個入口行為一字不差；助手同時補齊兩個出場距離 |

### 沿用的既有規則（不生第二套說法）

| 既有規則 | 這一刀怎麼對待它 |
|:---|:---|
| 買不起就跳過這次開倉，重演繼續走 | **完全沿用**，只是門檻多算了一筆進場成本 |
| 押多少的三種模式與它們的驗證 | **一個字都不改** |
| 進出場成交在該棒收盤價 | 不變 |
| 出場價位（止損止盈）的判斷與時序 | 不變。成本在平倉之後才算，不影響哪一棒出場 |
| 同一時間最多一個部位 | 不變 |
| 還開著的那一注不進交易明細 | 不變 |
| 拒絕時整次拒絕、不回部分結果 | 不變 |

### Edge Cases

| 情況 | 行為 |
|:---|:---|
| 兩格都留白 | 一概不計；每一個數字與這一刀之前逐字相同 |
| 只填進場 | 出場沿用同一個費率 |
| 只填出場 | 進場不收、出場收 |
| 成本率正好 100 | 允許。全押時部位與成本各半 |
| 全押且可用資金極小 | 可押上限仍為正就開得成；算出來押不到錢才跳過 |
| 押固定金額正好等於可用資金 | 付不起進場成本 → **跳過**（這一刀之前開得成，但只在填了成本時才變） |
| 押百分之百 | 同上 → **跳過**。與全押不同是對的：全押沒有數字、會自己縮到付得起；百分之百是使用者打出來的一個數字，付不起它與它的成本就跳過 |
| 一趟原地打平 | 損益是負的兩筆成本；不算贏 |
| 走完時還開著一注 | 只算進場成本；最後剩多少樂觀一筆出場成本 |
| 一筆交易都沒發生 | 累計成本 0；勝率照舊「不適用」 |
| 做空 | 出場成本看成交金額，不看帳面價值 |

## 6. Non-Functional Requirements

| 項目 | 要求 |
|:---|:---|
| 正確性 | 金額運算一律精確小數，**不得出現浮點數** |
| 相容性 | 不填成本時，既有的每一條驗收與每一張成績單**逐字不變**——這是本刀最硬的一條 |
| 效能 | 每一棒多幾次乘法，重演仍是一次走訪，無額外取數 |
| 可觀測性 | 每一筆交易帶自己的兩個成本數字，使用者隨時能把淨額還原回毛額 |
| 誠實性 | 成績單的說明要寫明兩件事：**未平倉那一注沒有預扣出場成本**、**不支援每筆最低手續費** |

## 7. Dependencies & Risks

| 項目 | 說明 | 對策 |
|:---|:---|:---|
| 三個專案同時動 | 後端、連接器、前端各有一份表單與一份成績單 | 後端先落地，連接器與前端各自跟上；三邊共用同一組欄位語意 |
| 勝率語意改變 | 既有讀者對「勝率」的理解會變 | 只在填了成本時才變；每一筆附上成本數字，可還原毛額 |
| 全押語意改變 | 「全押」從此是「錢全部變成這筆交易」 | 只在填了成本時才變；不填時可押上限就是可用資金本身 |
| 未平倉樂觀一筆出場成本 | 已知且刻意 | 寫進成績單說明 |
| 每筆最低手續費不支援 | 小額交易的成本會被算少 | 寫進成績單說明，列為明知故犯 |

## 8. Appendix

### 新增業務詞彙（需補進 `.sdd/UL-MAP.md`）

| 業務詞彙 | 定義 |
|:---|:---|
| **交易成本** | 一次重演要不要模擬手續費與稅，以及進出場各收成交金額的幾個百分點：**進場成本率**與**出場成本率**合起來的那一組。整組選填，兩格都留白即完全不計 |
| **進場成本率** | 開倉時要付的，佔押下去金額的百分點。不得為負、不得超過 100 |
| **出場成本率** | 平倉時要付的，佔成交金額的百分點。**留白即沿用進場成本率** |
| **進場成本** | 這一次開倉實際付掉的錢 ＝ 押的金額 × 進場成本率 |
| **出場成本** | 這一次平倉實際付掉的錢 ＝ 單位數 × 出場價 × 出場成本率 |
| **成交金額** | 一次進出場實際成交的金額。進場是押下去的金額，出場是單位數 × 出場價（**不是**那一注帳面上值多少） |
| **可押上限** | 可用資金裡最多能拿去當部位的金額 ＝ 可用資金 ÷ (1 + 進場成本率)。不計成本時就是可用資金本身 |
| **累計成本** | 一次重演總共付掉的錢：已平倉交易的所有成本 ＋ 還開著那一注已付的進場成本 |

### 需要修訂的既有詞彙

| 既有詞彙 | 修訂內容 |
|:---|:---|
| **回測不計入的成本** | 手續費從這一列**移出**——填了成本率就真的模擬，留白才不計。滑點、槓桿與保證金仍在列 |
| **可用資金** | 開倉時多減一筆進場成本；平倉時收回的現金已扣掉出場成本 |
| **勝率** | 讀的是**淨額**。賺不過成本的那一趟不算贏 |
| **已平倉交易** | 多帶進場成本與出場成本兩個數字；損益改為淨額 |
| **成績單** | 多一個累計成本 |

**押多少**、**全押**、**押幾成**、**押固定金額**、**倉位**、**倉位方向**、**交易模式**、
**出場價位**、**出場原因**、**資金曲線**、**最後剩多少**、**最大回撤**、**開倉次數**、
