# Product Requirements Document — 只做空這種交易模式

**Status:** Draft
**Version:** v1.0
**Owner:** James Hsueh
**Stakeholders:** Engineering, QA

---

## 1. Background & Goal

### Problem Statement

交易模式現在有三種：**多空反手**、**現貨**、**槓桿做多**。它們涵蓋了
「兩邊都做」與「只做多」，但**沒有一種是「只做空」**。

想在合約帳戶上這一段時間只做空的人，三個選項一個都不合用：

- **多空反手** 會反手叫他做多，而那正是他想避開的。
- **現貨** 與 **槓桿做多** 永遠不會開空倉，他一次空單都做不到。

他現在唯一的辦法是**在交易策略裡塞一個永遠不會成立的買入條件**，
讓多空反手那套規則只剩賣出。那個辦法做得出來，但**規則說的話與它做的事對不起來**：
那份交易策略上寫著「多空反手」，畫面、訊息、成績單都這麼寫，而它從頭到尾只做空。
下一個讀到它的人沒有任何方法看出這件事。

### Expected Outcome

- 使用者在建立交易策略時看得到**四個**交易模式選項，並挑得到「只做空」。
- 一份標示「只做空」的交易策略，其成績單、機器人訊息與實際行為**三者一致**：
  每一筆交易的方向都是做空，訊息叫他做空與出場，從不叫他做多。
- **既有的三種模式行為逐字不變**：已存在的交易策略、機器人與成績單，
  在這一刀之後沒有任何一項數字或字句改變。

### Out of Scope

- **「進了場就不理信號，只等止損止盈」這個開關。** 那問的是「出場由誰決定」，
  不是「這套規則做得了哪一邊」。
- **兩邊都做、但不反手的模式。** 沒有人開口要。
- **自動辨認並改寫既有那些用變通辦法拼出來的交易策略。**
  一個永遠不成立的條件與一個剛好還沒成立的條件長得一模一樣，系統分不出來。
- **強制平倉本身的任何規矩。** 全部沿用，一條都不改。
- **資金費率。**
- **機器人真的去下單。**

---

## 2. User Personas

- **Primary Role:** 交易策略的擁有者 —— 在合約帳戶上操作、這一段時間判斷行情往下、
  或已經觀察到自己做空的那一半表現優於做多的那一半，因此只想收到做空建議的人。
- **Secondary Role:** 助手的使用者 —— 用自然語言請助手替他寫或改交易策略的人。
- **Usage Context:** 在畫面上建立與修改交易策略、發動重演讀成績單；
  機器人則在背景固定間隔醒來，把結論送到他手機上。

## 3. User Stories & Acceptance Criteria

### US-01 — 挑得到「只做空」這個交易模式 [priority: P0]

**As a** 交易策略的擁有者，**I want** 把一份交易策略標示為只做空，
**so that** 規則說的話與它實際做的事對得起來，而不必靠一個永遠不成立的條件去騙它。

```gherkin
Scenario: 存一份只做空的交易策略
  Given 一份交易策略的交易模式填「只做空」
  When 存這份交易策略
  Then 存得起來，而且讀回來時交易模式仍是「只做空」

Scenario: 交易模式沒填仍然是多空反手
  Given 一份交易策略完全沒填交易模式
  When 存這份交易策略
  Then 存得起來，而且讀回來時交易模式是「多空反手」

Scenario: 交易模式填了認不得的值就整份拒絕
  Given 一份交易策略的交易模式填了一個認不得的值
  When 存這份交易策略
  Then 整份被拒絕，並列出四種可選：多空反手、現貨、槓桿做多、只做空
  And 這份交易策略沒有被存下來

Scenario: 既有的交易策略不會被自動改掉
  Given 一份在這一刀之前就存在、交易模式是「多空反手」的交易策略
  When 讀這份交易策略
  Then 交易模式仍是「多空反手」

Scenario: 其餘三種模式照舊存得起來
  Given 一份交易策略的交易模式填「現貨」或「槓桿做多」或「多空反手」
  When 存這份交易策略
  Then 存得起來，行為與這一刀之前逐字相同
```

### US-02 — 只做空的倉位行為是槓桿做多的鏡像 [priority: P0]

**As a** 交易策略的擁有者，**I want** 只做空的每一棒都只往做空那一邊動作，
**so that** 我永遠不會在成績單上看到一筆我沒打算做的多單。

```gherkin
Scenario: 空手時聽到賣出就開空倉
  Given 交易模式是只做空
  And 手上空手
  When 這一棒的信號是賣出
  Then 以該棒收盤價開一個空倉

Scenario: 已持有空倉時再聽到賣出當作沒聽到
  Given 交易模式是只做空
  And 手上已持有空倉
  When 這一棒的信號是賣出
  Then 倉位不動，且不計為一次開倉

Scenario: 持有空倉時聽到買入就平倉回現金
  Given 交易模式是只做空
  And 手上持有空倉
  When 這一棒的信號是買入
  Then 空倉被平掉，該倉位的價值回到可用資金
  And 之後手上空手，沒有開出多倉

Scenario: 空手時聽到買入什麼都不發生
  Given 交易模式是只做空
  And 手上空手
  When 這一棒的信號是買入
  Then 沒有開出任何倉位，開倉次數不變，可用資金不變

Scenario: 持有時倉位不動
  Given 交易模式是只做空
  And 手上持有空倉
  When 這一棒的信號是持有
  Then 倉位不動，且不記錄任何一筆交易

Scenario: 整段交易明細裡不會出現多倉
  Given 一次只做空的重演已經跑完
  When 讀交易明細
  Then 每一筆的方向都是做空

Scenario: 與變通辦法跑出同一張成績單
  Given 同一段歷史與同一組信號
  And 一次用「只做空」，另一次用「多空反手且買入條件永遠不成立」
  When 比對兩張成績單
  Then 兩張的總報酬率、最大回撤、勝率與開倉次數完全一樣
```

### US-03 — 只做空借得到錢，也會被強制平倉 [priority: P0]

**As a** 交易策略的擁有者，**I want** 只做空能像其他合約模式一樣上槓桿並被模擬強制平倉，
**so that** 成績單反映的是我在合約帳戶上真正會遇到的風險。

```gherkin
Scenario: 只做空上槓桿被接受
  Given 交易模式是只做空
  And 槓桿倍數是 3
  When 發動重演
  Then 重演被接受，曝險是押注金額的 3 倍
  And 會模擬強制平倉

Scenario: 槓桿倍數留白時當作沒有槓桿
  Given 交易模式是只做空
  And 槓桿倍數留白
  When 發動重演
  Then 重演被接受，成績單上強平出場筆數為 0

Scenario: 槓桿倍數填一時當作沒有槓桿
  Given 交易模式是只做空
  And 槓桿倍數是 1
  When 發動重演
  Then 重演被接受，成績單上強平出場筆數為 0

Scenario: 槓桿倍數小於一就整份拒絕
  Given 交易模式是只做空
  And 槓桿倍數是 0.5
  When 發動重演
  Then 整份被拒絕，並說槓桿倍數不得小於一

Scenario: 現貨上槓桿仍然整份拒絕
  Given 交易模式是現貨
  And 槓桿倍數是 3
  When 發動重演
  Then 整份被拒絕，並說現貨借不到錢

Scenario: 只做空的強平價在進場價上方
  Given 交易模式是只做空
  And 一個空倉的進場價是 100、槓桿 5、維持保證金率 0.5%
  When 算這個倉位的強平價
  Then 強平價高於 100

Scenario: 價格往上越過強平價就被強制出場
  Given 一個只做空的空倉，槓桿 5，強平價高於進場價
  When 某一棒的最高價越過強平價
  Then 這個倉位在強平價被強制出場
  And 這一注收回 0
  And 這一筆的出場原因是強平出場

Scenario: 止損比強平近時先碰到止損
  Given 一個只做空的空倉，槓桿 5
  And 止損價與強平價都在進場價上方，且止損價比強平價低
  When 某一棒的最高價越過兩者
  Then 這個倉位在止損價出場
  And 這一筆的出場原因是止損出場
```

**As a** 機器人的擁有者，**I want** 引用一份只做空交易策略的機器人能填槓桿，
**so that** 我的建議部位與那份規則做得到的事一致。

```gherkin
Scenario: 引用只做空、填槓桿，存得起來
  Given 一台機器人引用一份只做空的交易策略
  And 建議部位的槓桿倍數是 1.8
  When 存這台機器人
  Then 存得起來

Scenario: 引用只做空、槓桿留白，存得起來
  Given 一台機器人引用一份只做空的交易策略
  And 建議部位的槓桿倍數留白
  When 存這台機器人
  Then 存得起來

Scenario: 引用只做空、槓桿小於一，整台拒絕
  Given 一台機器人引用一份只做空的交易策略
  And 建議部位的槓桿倍數是 0.5
  When 存這台機器人
  Then 整台被拒絕，並說槓桿不得小於一

Scenario: 引用現貨、填槓桿，仍然整台拒絕
  Given 一台機器人引用一份現貨的交易策略
  And 建議部位的槓桿倍數是 1.8
  When 存這台機器人
  Then 整台被拒絕，並說現貨借不到錢
```

### US-05 — 只做空的機器人訊息講出他真正要做的動作 [priority: P0]

**As a** 機器人的擁有者，**I want** 訊息用我做得到的動詞，
**so that** 我讀完就知道要去做什麼，不必自己換算。

```gherkin
Scenario: 結論是賣出時寫做空
  Given 一台只做空的機器人
  When 這一輪的結論是賣出
  Then 訊息的結論那一句寫「做空」
  And 訊息裡多一行寫出交易模式是「只做空」

Scenario: 結論是買入時寫出場
  Given 一台只做空的機器人
  When 這一輪的結論是買入
  Then 訊息的結論那一句寫「出場」
  And 那一句不寫「做多」，也不寫「買入」

Scenario: 有槓桿時印保證金與名目
  Given 一台只做空的機器人，部位資金 50000、全押、槓桿 3
  When 讀開倉那一輪的訊息
  Then 訊息印出保證金 50000 與名目 150000 兩行

Scenario: 槓桿留白時不印那兩行，但仍印交易模式
  Given 一台只做空的機器人，槓桿留白
  When 讀開倉那一輪的訊息
  Then 訊息不印保證金倍數與名目那兩行
  And 訊息仍印出交易模式那一行

Scenario: 空倉的止損寫往上
  Given 一台只做空的機器人，建議部位填了停損距離
  When 讀開倉那一輪的訊息
  Then 止損那一行寫的方向是「往上」

Scenario: 其餘三種模式的訊息一個字都沒改
  Given 一台現貨、槓桿做多或多空反手的機器人
  When 讀訊息
  Then 結論那一句的動詞與是否印交易模式那一行，都與這一刀之前逐字相同

Scenario: 各來源怎麼說那一段照舊
  Given 一台只做空的機器人
  When 讀「各來源怎麼說」那一段
  Then 每一行仍寫買入、賣出或持有
```

**As a** 使用者，**I want** 在畫面上與對助手說話時都挑得到只做空，
**so that** 我不必回頭去學那個變通辦法。

```gherkin
Scenario: 畫面上看得到四個選項
  Given 使用者在畫面上建立一份交易策略

Scenario: 既有三個選項的位置沒有移動
  Given 使用者在畫面上建立一份交易策略
  When 看交易模式那一組選項的排列順序

Scenario: 助手聽懂「只想做空」

Scenario: 助手不再用變通辦法

Scenario: 重演一支策略腳本時也挑得到
```

## 4. Business Flow & Logic

### Core Business Rules

**R1 — 交易模式的取值。** 四選一：多空反手、現貨、槓桿做多、只做空。
留白即多空反手；認不得的值一律整份拒絕並列出四種。

**R2 — 每一棒的信號讓倉位變成什麼樣子。**

| 交易模式 | 買入 | 賣出 | 持有 |
| :--- | :--- | :--- | :--- |
| 多空反手 | 目標持多 | 目標持空 | 不變 |
| 現貨 | 目標持多 | 目標空手 | 不變 |
| 槓桿做多 | 目標持多 | 目標空手 | 不變 |
| **只做空** | **目標空手** | **目標持空** | 不變 |

「目標空手」時若手上本來就空手，**什麼都不發生**：不開倉、不計次、可用資金不變。
「目標持多／持空」時若手上已是同方向，**當作沒聽到**。

**R3 — 誰借得到錢。** 多空反手、槓桿做多、只做空借得到；現貨借不到。
只做空之所以借得到，是因為放空本來就要先借到東西才賣得出去。

**R4 — 強平在哪一邊。** 由倉位方向決定，不由交易模式決定：
多倉的強平價在進場價下方，空倉在上方。只做空只有空倉，所以永遠在上方。
這一條是既有規則，本次不新增任何計算。

**R5 — 結論那一句的動詞。** 由兩個問題共同決定，而不是一個：

| 做得了多嗎 | 做得了空嗎 | 買入寫成 | 賣出寫成 | 印交易模式那一行嗎 |
| :---: | :---: | :--- | :--- | :---: |
| 是 | 是 | 做多 | 做空 | 印 |
| 是 | 否 | 買入 | 出場 | 借得到錢才印 |
| **否** | **是** | **出場** | **做空** | **印** |

「做不做得了空」單獨一個問題答不出只做空的動詞——它做得了空卻做不了多。

**R6 — 既有行為不變。** 前三種模式的每一個數字與每一句話，
在這一刀之後與之前逐字相同。

### Edge Cases

- **整段重演一筆交易都沒觸發**：不是錯誤，成績單照出，開倉次數 0。
- **只做空、槓桿留白**：不模擬強制平倉，強平出場筆數 0。
- **同一棒同時碰到止損與強平**：沿用既有規則，止損較近者先到；
  同價時沿用既有的判法，本次不新增規則。
- **既有機器人正在跑**：不被停掉、不被刪掉、訊息照送。

- **Key Interactions:**

## 7. Dependencies & Risks

### External Dependencies

無外部服務。三處要一起改：後端的規則與訊息、畫面上的選項、助手的說明。

### Known Risks

- **最大的風險是「動詞寫錯」。** 在此之前，「結論那一句怎麼寫」只靠
  「做不做得了空」一個問題就答得出來。只做空把那個問題問壞了——
  它做得了空，卻做不了多。若照舊只問那一個問題，它的買入會被寫成「做多」，
  而那是一句使用者永遠做不到的話，而且**訊息看起來完全正常**，沒有任何地方會報錯。
- **次要風險是漏掉某一處的選項清單。** 拒絕時要說出「有哪四種」，
  畫面上要有四個，助手要認得四種。少改一處不會壞掉，只會讓使用者
  在某一扇門後面看不到這個選項——而那種缺席看起來像功能沒做，不像漏改。
