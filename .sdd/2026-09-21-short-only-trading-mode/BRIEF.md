# 只做空這種交易模式 — Requirements Brief

## Goal

交易模式現在有三種：**多空反手**、**現貨**、**槓桿做多**。

前一刀補上槓桿做多時，明白地把它的鏡像留在範圍外，理由寫得很清楚：
**「只放空不做多」沒有人開口要，不為了對稱生一個沒人用的選項。**

**現在有人開口了。**

想做這件事的人是這樣的：他在合約帳戶上，這一段時間只想做空——
可能是他判斷行情往下，可能是他發現自己做多的那一半一直在賠而做空的那一半在賺。
他要的是一台**只會叫他做空、永遠不會叫他做多**的機器人。

**而他現在挑不到那個選項。**

- 挑**多空反手**，他會被反手做多。那正是他想避開的。
- 挑**現貨**或**槓桿做多**，這兩種永遠不會開空倉，他一次空單都做不到。

於是他只剩一個辦法：**在交易策略裡塞一個永遠不會成立的買入條件**，
騙過多空反手那套規則，讓它有賣出、沒有買入。

那個辦法**做得出來，但它是個騙局**。那份交易策略上寫著「多空反手」，
畫面上、訊息上、成績單上都是這麼寫的，而它實際上從頭到尾只做空。
**規則說的話與它做的事對不起來**，而下一個讀到它的人（包括三個月後的他自己）
沒有任何方法看出這件事。

這個切片補上第四種交易模式：**只做空**。
倉位的行為是**槓桿做多的鏡像**——只做空、買入就平倉回現金、
空手時聽到買入什麼都不發生——**而且它借得到錢**。

## Requirements

### 交易模式從三種變四種

交易模式從此**四選一**：**多空反手**、**現貨**、**槓桿做多**、**只做空**。

- **只做空的倉位行為，是槓桿做多的鏡像，一個字都不多。**
  聽到賣出，空手就開空倉、已是空倉當作沒聽到；
  聽到買入，有空倉就平掉、錢回到可用資金、之後空手；
  **空手時聽到買入什麼都不發生**；聽到持平不動作。
  **永遠不會出現多倉**，交易明細每一筆的方向都是做空。
  同一棒不會既平又開。
- **只做空借得到錢**，理由不是為了方便，是**放空本來就要先借到東西才賣得出去**。
  這一條在前一刀就寫下來了，只是當時沒有一種模式用得上它。

**用「只做空」這個詞，不叫「槓桿做空」也不叫「永續做空」。**
命名照能力、不照場所，與槓桿做多同一套規矩。
而「槓桿」兩個字不進名字，是因為**它沒得選**——只做空不可能不借錢，
寫進去等於說有一種「不借錢的只做空」，而那個東西不存在。

### 四種模式各自能做什麼

| 交易模式 | 買入是什麼意思 | 賣出是什麼意思 | 借得到錢嗎 |
| :--- | :--- | :--- | :--- |
| 多空反手 | 平掉空倉，同一棒反手開多 | 平掉多倉，同一棒反手開空 | 借得到 |
| 現貨 | 空手就開多倉 | 平倉回現金，空手時什麼都不發生 | **借不到** |
| 槓桿做多 | 空手就開多倉 | 平倉回現金，空手時什麼都不發生 | 借得到 |
| **只做空** | **平倉回現金，空手時什麼都不發生** | **空手就開空倉** | **借得到** |

- **「做得了哪一邊」與「借不借得到錢」還是兩個問題**，只是第一個問題的答案
  從三種變四種：只做多、只做空、兩邊都做、兩邊都不做（不存在，那不是交易）。
  加上借不借錢，成立的組合就是這四種模式。
- **第五種（只做空、卻借不到錢）不存在**，理由與前一刀寫的同一句：
  放空要先借到東西才賣得出去。

### 沒填會怎樣、填錯會怎樣——一個字都不改

- **沒填**仍然是**多空反手**。
- **填一個認不得的值，整份拒絕**，並說出現在有哪**四**種可選——
  唯一的變化是那句話裡又多了一個選項。
- **既有的每一份交易策略照舊**，沒有任何一份會被自動改成只做空。

### 重演：只做空借得到錢，而且會被強制平倉

- 交易模式是**只做空**、槓桿倍數大於一 → **接受**，照既有的槓桿規矩重演。
- 強制平倉的規矩**一條都不新增**，全部沿用既有的那一套。
- **只做空只會有空倉，所以強平價永遠在進場價上方**——
  價格往上走才是它撐不住的方向。這一點與槓桿做多恰好相反，
  而那個相反不需要新規則：既有的那一套本來就照倉位方向決定強平在哪一邊。
- 四種模式在槓桿倍數留白時，結果與這一刀之前**逐字相同**。

### 機器人：只做空也擋得住不該有的槓桿

- 機器人引用一份**只做空**交易策略、填大於一的槓桿倍數 → **存得起來**。
- 其餘三種模式的判法**一個字都不改**。

### 機器人的訊息：講出它真正要人做的動作

**只做空的訊息，兩個動詞都與既有的任何一種模式不同**，
而這正是它需要自己一套寫法的理由。

- **賣出那一側寫 `做空`。** 他要做的是開一個倉位，不是把手上的東西賣掉。
  這與多空反手的賣出同一個字，因為那一刻兩者要做的事確實一樣。
- **買入那一側寫 `出場`**，不寫 `做多`、也不寫 `買入`。
  他**做不了多**，所以 `做多` 是一句他做不到的話；
  而 `買入` 對空手的他一樣沒有意義——買入**照信號本身就會送出**，
  而信號從來不知道他手上有沒有空倉。`出場` 是持倉的人與空手的人都照得了的一句。
- **多一行講出交易模式**，與多空反手、槓桿做多一樣——它借得到錢，
  而借錢開的倉位會被強制平倉，那是讀訊息的人必須知道的差別。
- **槓桿與名目部位那兩行照既有規矩印。**
- **各來源怎麼說那一段不動**，照樣寫買入／賣出／持有。

### 使用者挑得到這個新選項

- 畫面上建立與修改交易策略的地方，交易模式**從三個選項變四個**。
- 助手在替使用者寫或改交易策略時，**認得這四種**，並且說得出它們差在哪——
  使用者說「我這段時間只想做空」時，它要挑得到只做空，
  而**不是**退而求其次挑多空反手再想辦法讓買入不成立。
- 重演一支**策略腳本**時（使用者自己指定交易模式）同樣認得這四種。

## Out of Scope

- **「進了場就不理信號，只等止損止盈」這個開關。** 那是另一件事：
  它問的是「出場由誰決定」，不是「這套規則做得了哪一邊」。
  想要那個效果的人，現在照樣可以讓反向條件不成立——
  而這一刀讓他至少不必為了**方向**去騙那份規則。
- **兩邊都做、但不反手的模式**（做多平倉回現金、做空也平倉回現金、不在同一棒反手）。
  沒有人開口要，理由與前一刀把只做空留在範圍外時一樣。
- **自動把既有那些「多空反手 ＋ 永遠不成立的買入條件」的交易策略改成只做空。**
  系統認不出使用者當初是不是在用那個變通辦法——一個永遠不成立的條件與
  一個剛好還沒成立的條件長得一模一樣。改不改由他決定。
- **強制平倉本身的任何規矩。** 全部沿用，一條都不改。
- **資金費率。** 與這一刀無關，理由與前一刀一字不差。
- **機器人真的去下單。** 從頭到尾只送建議，這件事不變。

## Context / Background

- **為什麼這一刀的訊息寫法必須單獨想過。**
  在此之前，「這個模式的結論該寫成什麼動詞」只靠一個問題就答得出來：
  **做不做得了空**。做得了就寫做多／做空，做不了就寫買入／出場。
  **只做空把那個問題問壞了**——它做得了空，卻做不了多。
  照舊問下去，它的買入會被寫成「做多」，而那是一句它永遠做不到的話。
  真正該問的從一個問題變成兩個：**做得了多嗎**、**做得了空嗎**。

- **為什麼「槓桿」不寫進名字。**
  槓桿做多之所以叫槓桿做多，是因為它與現貨的**唯一**差別就是借不借得到錢，
  不寫進去就跟現貨分不出來。只做空沒有這個問題：**它沒有一個不借錢的版本**，
  寫進去反而會讓人以為有。

- **使用者現在就在用那個變通辦法。**
  他手上已經有一份「多空反手 ＋ 一個永遠不成立的買入條件」的交易策略，
  而且它跑得出成績單。這一刀不是為了讓那件事變得可能——
  它本來就可能——而是為了讓**規則說的話與它做的事對得起來**。

- 本切片新增的業務詞彙，需補進 `.sdd/UL-MAP.md`：**只做空**；
  並修訂既有的 **交易模式**（從三選一改為四選一）。
